Словарь и быстрые фразы: имена, названия и адрес одним словом

Модель не знает фамилию вашего клиента и название вашего проекта. Словарь это исправляет, а быстрые фразы вставляют длинный текст по одному слову.

Бесплатно2 мин чтения

Два раздела

«Слова»: как писать то, что модель слышит иначе. «джира» → Jira, «Ниматрон» → Nemotron.

«Быстрые фразы»: по слову вставляется готовый текст. «мой адрес» → полный адрес с индексом.

Добавить слово

  1. Вкладка «Словарь» → «Слова» → «+ Добавить слово».
  2. «Как писать»: правильное написание, например фамилия клиента.
  3. «Распознанное слово»: как модель пишет его сейчас. Не знаете, оставьте пустым.

Похожие слова. Если слово услышано с небольшой ошибкой, Писарь всё равно напишет его как в словаре: «Ниматрон» и «Немотрон» → Nemotron. Русские фамилии сохраняют окончание: «Пажидаевой» → «Пожидаевой».

Быстрая фраза

  1. Вкладка «Словарь» → «Быстрые фразы».
  2. Слово: «мой адрес». Текст: адрес полностью.
  3. Диктуйте «мой адрес» в любом поле: вставится полный текст.

Готовый словарь

Английские названия, которые модель написала русскими буквами, Писарь пишет латиницей: «джира» → Jira, «в телеграме» → в Telegram. Выключается вверху «Слов», если хотите начать с нуля. Свои слова можно сохранить файлом: ⋮ → «Скачать».

Плюсы и минусы

Плюсы

  • Словарь без лимита.
  • Быстрые фразы экономят время на адресах, реквизитах, шаблонах ответов.
  • Всё на телефоне.

Минусы и ограничения

  • Короткие слова, до 5 букв, исправляются, только если звучат точно так же.
  • Не каждое название получается с первого раза: иногда нужно добавить, как модель его слышит.
  • «Подсказывать названия модели» помогает с редкими словами, но распознавание идёт заметно дольше. По умолчанию выключено.
  • «Учиться на правках» работает только там, где Писарь видит текст поля, и только до отправки. По умолчанию выключено.
